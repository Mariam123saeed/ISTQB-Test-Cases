# NTI Software Testing – ISTQB Test Cases

This repository contains practical **Software Testing tasks** completed during the **NTI Software Testing Engineer Track**, focusing on **ISTQB Foundation concepts and Test Case Design**.

Each task includes the **demo/reference image** and the corresponding **Excel test cases**.

## 📂 Tasks

### Task 01 – Signup Form

Test cases designed for a Signup Form.

### Task 02 – Register Page

Test cases designed for a Register Page.

### Task 03 – Add Offer Page

Test cases designed for an Add Offer Page.

### Task 04 – Create MediaSpace

Test cases designed for the Create MediaSpace functionality.

### Task 05 – Workflow Relations

Test cases designed for Workflow Relations.

## 🧪 Testing Activities

The tasks cover practical application of:

* Test Case Design
* Functional Testing
* Positive & Negative Testing
* Boundary Value Analysis
* Equivalence Partitioning
* Decision Table Testing
* Requirement-based Testing
* Test Data Design
* Expected Result Definition
